# Contributing to this Python Practice Repository

Thanks for helping improve this learning repository.

## How to contribute

1. Fork or clone the repository.
2. Create a new branch for your work.
3. Add or improve Python scripts, exercises, or documentation.
4. Run the tests locally.
5. Open a pull request with a clear description.

## Contribution ideas

Good contributions for this project include:
- improving code readability and formatting
- adding missing README documentation
- organizing files into folders by topic
- adding tests for beginner scripts
- fixing small bugs in exercises
- creating beginner-friendly mini projects

## Naming and structure

Please keep names simple and descriptive.

Examples:
- `reverse_string.py`
- `sum_of_digits.py`
- `todo_cli.py`

Use clear, consistent naming and avoid overly complicated file names when possible.

## Code style

- Use Python 3
- Prefer readable variable names
- Add short comments when needed
- Keep scripts beginner-friendly
- Use functions where they improve clarity

## Testing

Before submitting a PR, run:

```bash
pip install -r requirements.txt
pytest
```

## Pull request expectations

Your pull request should include:
- a clear title
- a short description of what changed
- any tests added or updated
- notes about why the change is useful

## A note for learners

This repository is meant to support learning, so beginner-friendly improvements are especially valuable.
