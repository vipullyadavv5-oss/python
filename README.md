# Python Practice Repository

This repository is a beginner-friendly Python learning workspace containing small practice scripts, algorithm exercises, and mini-projects.

The goal is to help learners practice Python fundamentals such as:
- variables and input/output
- loops and conditionals
- strings and numbers
- arrays and lists
- basic CLI programs
- problem-solving exercises

## Repository overview

The repository includes examples such as:
- `reverse_string.py`
- `count_digits.py`
- `sum_of_digits.py`
- `todo_cli.py`
- many beginner-level algorithm and practice files

## Quick start

1. Make sure Python 3 is installed.
2. Clone the repository.
3. Run any script directly:

```bash
python reverse_string.py
```

## Running tests

This repository includes a simple `pytest` setup for demo validation.

```bash
pip install -r requirements.txt
pytest
```

## Suggested learning path

- Start with simple beginner scripts like string, number, and list operations.
- Move to algorithmic exercises such as Fibonacci, palindrome, and reverse operations.
- Practice mini projects such as the To-Do CLI app.
- Keep improving naming, documentation, and code readability.
